# 访问与登录 { #sign-in }

1.10.7 版本新增了登录方式。请为此实例确认一次访问设置；您的账户、缓存和预填充设置将保留。之后可在 **用户 → 账户 → 访问与登录** 中更改。

## 用户应如何登录？

**本地账户**

**用户名和密码**

使用本地账户登录。登录时无需输入 API 密钥。

请使用独立密码并妥善保管。

**API 密钥、用户名和密码**

同时要求实例密钥和本地账户。

实例密钥是共享的。请妥善保管密钥和个人密码。

**单点登录**

**API 密钥和单点登录**

使用获准的单点登录账户和实例 API 密钥登录。

密钥由多人共用，请妥善保管。

需要 HTTPS

**单点登录**

使用 Google、GitHub、Microsoft、Apple 或其他 OpenID Connect 服务登录。无需输入本地密码或 API 密钥。

仅允许获准账户登录。请保留服务器访问权限以便恢复。

需要 HTTPS

**无需登录**

**无需身份验证**

无需用户名、密码或 API 密钥即可打开应用。

任何能够访问此应用的人都可使用管理功能。仅适用于所有人员和设备均受信任的网络。

所有模式都会保留实例 API 密钥，用于验证所有权和恢复；密钥归第一个账户（主管理员）所有。

在保存模式之前，`Security__EnableAuthentication` 决定默认值。`true`（内置默认值）为 **API 密钥、用户名和密码**。`false` 为 **无需身份验证**。已保存的模式不会被该变量替换。

支持本地 HTTP 访问。凭据和会话以未加密方式传输，因此在不可信网络上请使用 HTTPS。

通过 HTTP 访问时无法使用单点登录。请使用 HTTPS 连接此应用。

!!! note "重新生成 API 密钥"
    **重新生成 API 密钥** 会替换实例 API 密钥，之前的密钥随即失效。

    ```bash
    docker exec lancache-manager cat /data/security/api_key.txt
    ```

## 单点登录

这里没有中心登录服务。在服务商处注册应用，然后填入凭据。Google、GitHub、Microsoft、Apple 和「其他（OpenID Connect）」可以同时连接。每种只保存一份；再次保存会更新该服务。

| 服务商 | 所需信息 |
|---|---|
| Google | 客户端 ID 和客户端密钥 |
| GitHub | 客户端 ID 和客户端密钥 |
| Microsoft | 应用程序（客户端）ID、客户端密钥和目录（租户）ID。使用租户 GUID，个人账户填 `consumers`。`common` 和 `organizations` 会被拒绝 |
| Apple | Services ID、Team ID、Key ID 和 `.p8` 密钥。应用会自行生成 Apple 的客户端密钥。必须使用 HTTPS 域名；localhost 和 IP 地址会被拒绝 |
| 其他（OpenID Connect） | HTTPS 签发者 URL、客户端 ID 和客户端密钥 |

设置页显示 **登录回调 URL** 和 **测试回调 URL**。把两个地址都复制到服务商的应用注册中。这些返回 URL 已内置于应用中。复制前，请通过预定的登录地址打开应用。

**测试连接**。用于测试此连接的账户会自动关联到主管理员。启用前会测试连接。测试失败将保留当前登录设置。

其他用户按主体标识符授权，而不是电子邮件地址或显示名称。GitHub 使用数字账户 ID。Microsoft 使用 `租户 GUID:对象 GUID`。

### 回调地址

单点登录需要 HTTPS。设置界面即使在 localhost 上也要求 HTTPS。只在局域网或 VPN 内解析的域名即可，无需公网托管。除 Apple 以外的服务商，仅当主机是 localhost 或回环地址时，服务器才接受 HTTP 地址，而设置界面仍然要求 HTTPS。Apple 要求 HTTPS 域名，并拒绝 localhost 和任何 IP 地址。

## 切换模式

现有账户会话仍然有效。可在用户页面的会话列表中结束这些会话。切换到需要登录的模式后，共享的无身份验证访问将被撤销。由单点登录创建的账户尚无密码，请在切换到 **用户名和密码** 或 **API 密钥、用户名和密码** 之前设置密码。

如果单点登录导致无法进入，请在宿主机上运行：

```bash
./data/scripts/reset-main-admin-password.sh
```

该脚本会重启应用并由此打开这一小时，然后发送实例 API 密钥和主机恢复令牌。请输入**用户名**、**密码**、**确认密码**和 **API 密钥**。详见[密码恢复](password-recovery.md)。
